# 🔷 **PART 1: Grouped Statistics**

---

## 🔹 **Cell 5: Summary Statistics Grouped by Species**

```python
group_stats = df.groupby('species')[[
    'sepal_length',
    'sepal_width',
    'petal_length',
    'petal_width'
]].agg(['mean', 'median', 'min', 'max', 'std'])

group_stats
```

**Explanation:** Calculated mean, median, min, max, and standard deviation grouped by species.

---

## 🔹 **Cell 6: Create List for Each Category**

```python
group_list = df.groupby('species')['sepal_length'].apply(list)
group_list
```

**Explanation:** Created list of numeric values for each species.

---

# 🔷 **PART 2: Species-wise Analysis**

---

## 🔹 **Cell 7: Filter by Species**

```python
setosa = df[df['species'] == 'setosa']
versicolor = df[df['species'] == 'versicolor']
virginica = df[df['species'] == 'virginica']
```

**Explanation:** Separated dataset based on species.

---

## 🔹 **Cell 8: Basic Statistics**

```python
print("Setosa:\n", setosa.describe())
print("\nVersicolor:\n", versicolor.describe())
print("\nVirginica:\n", virginica.describe())
```

**Explanation:** Displayed statistical summary for each species.

---

## 🔹 **Cell 9: Percentiles**

```python
num_cols = df.select_dtypes(include='number').columns

print("Setosa Percentiles:\n", setosa[num_cols].quantile([0.25, 0.5, 0.75]))
print("\nVersicolor Percentiles:\n", versicolor[num_cols].quantile([0.25, 0.5, 0.75]))
print("\nVirginica Percentiles:\n", virginica[num_cols].quantile([0.25, 0.5, 0.75]))
```

**Explanation:** Calculated quartiles for each species.

---

## 🔹 **Cell 10: Standard Deviation**

```python
print("Setosa STD:\n", setosa[num_cols].std())
print("\nVersicolor STD:\n", versicolor[num_cols].std())
print("\nVirginica STD:\n", virginica[num_cols].std())
```

**Explanation:** Measured spread of data using standard deviation.

## 🔹 **Basic Concepts**

### 1. What is Descriptive Statistics?

**Answer:**
It summarizes and describes the main features of a dataset using measures like mean, median, and standard deviation.

---

### 2. What are measures of central tendency?

**Answer:**
They represent the central value of data:

* Mean
* Median
* Mode

---

### 3. What are measures of variability?

**Answer:**
They show the spread of data:

* Range
* Variance
* Standard deviation

---

## 🔹 **Mean, Median, Mode**

### 4. What is mean?

**Answer:**
Average of all values.

---

### 5. What is median?

**Answer:**
Middle value when data is sorted.

---

### 6. What is mode?

**Answer:**
Most frequently occurring value.

---

### 7. Which is affected by outliers?

**Answer:**
Mean is affected; median is not.

---

## 🔹 **Standard Deviation & Variance**

### 8. What is standard deviation?

**Answer:**
Measure of how spread out values are from the mean.

---

### 9. What is variance?

**Answer:**
Square of standard deviation.

---

### 10. What does high standard deviation mean?

**Answer:**
Data is widely spread.

---

### 11. What does low standard deviation mean?

**Answer:**
Data is closely clustered.

---

Q Difference Between describe() and info() in Pandas
1️⃣ df.info()
Purpose:
Used to get basic information about the dataset.
Output Includes:
Number of rows and columns
Column names
Data types (int, float, object)
Non-null values
Memory usage

2️⃣ df.describe()
Purpose:
Used to generate statistical summary of numeric columns.
Output Includes:
Count
Mean
Standard deviation
Minimum value
25%, 50%, 75% percentiles
Maximum value
