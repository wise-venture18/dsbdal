# 📘 **PS8: Data Visualization I **

## Titanic Dataset using Seaborn

---

# 🔷 **Cell 1: Import Libraries**

```python id="dv1"
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
```

**Explanation:**
Imported pandas for data handling and seaborn/matplotlib for visualization.

---

# 🔷 **Cell 2: Load Titanic Dataset**

```python id="dv2"
df = sns.load_dataset('titanic')

df.head()
```

**Explanation:**
Loaded inbuilt Titanic dataset from Seaborn library.

---

# 🔷 **Cell 3: Dataset Information**

```python id="dv3"
df.info()
df.describe()
```

**Explanation:**
Checked dataset structure and statistical summary.

---

# 🔷 **Cell 4: Check Dataset Shape**

```python id="dv4"
print("Shape of Dataset:", df.shape)
```

**Explanation:**
Displayed number of rows and columns.

---

# 🔷 **Cell 5: Count Plot (Survived)**

```python id="dv5"
sns.countplot(x='survived', data=df)

plt.title("Survival Count")
plt.show()
```

**Explanation:**
Visualized number of passengers who survived and did not survive.

---

# 🔷 **Cell 6: Count Plot (Gender-wise Survival)**

```python id="dv6"
sns.countplot(x='survived', hue='sex', data=df)

plt.title("Survival based on Gender")
plt.show()
```

**Explanation:**
Compared survival counts between males and females.

---

# 🔷 **Cell 7: Count Plot (Passenger Class)**

```python id="dv7"
sns.countplot(x='pclass', hue='survived', data=df)

plt.title("Passenger Class vs Survival")
plt.show()
```

**Explanation:**
Analyzed survival distribution across passenger classes.

---

# 🔷 **Cell 8: Histogram of Age**

```python id="dv8"
plt.hist(df['age'].dropna(), bins=30)

plt.title("Age Distribution")
plt.xlabel("Age")
plt.ylabel("Count")

plt.show()
```

**Explanation:**
Displayed distribution of passenger ages.

---

# 🔷 **Cell 9: Histogram of Fare**

```python id="dv9"
plt.hist(df['fare'], bins=30)

plt.title("Fare Distribution")
plt.xlabel("Fare")
plt.ylabel("Number of Passengers")

plt.show()
```

**Explanation:**
Visualized distribution of ticket prices (`fare`) using histogram.

---

# 🔷 **Cell 10: Boxplot of Fare**

```python id="dv10"
sns.boxplot(x='pclass', y='fare', data=df)

plt.title("Fare by Passenger Class")

plt.show()
```

**Explanation:**
Compared fare distribution across passenger classes.

---

# 🔷 **Cell 11: Heatmap of Correlation**

```python id="dv11"
numeric_df = df.select_dtypes(include=['number'])

sns.heatmap(numeric_df.corr(), annot=True)

plt.title("Correlation Heatmap")

plt.show()
```

**Explanation:**
Displayed correlation between numeric variables.

---

# 🔷 **Cell 12: Final Output**

```python id="dv12"
df.head()
```

**Explanation:**
Displayed final dataset preview.
