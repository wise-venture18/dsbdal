## 🔹 **Cell 4: Handle Missing Values**

```python
# Fill numeric with mean
num_cols = df.select_dtypes(include=np.number).columns

for col in num_cols:
    df[col] = df[col].fillna(df[col].mean())

# Fill categorical with mode
cat_cols = df.select_dtypes(include='object').columns

for col in cat_cols:
    df[col] = df[col].fillna(df[col].mode()[0])

# Remove duplicates
df.drop_duplicates(inplace=True)
```

**Explanation:**
Replaced missing numeric values with mean and categorical values with mode, then removed duplicate rows to ensure clean data.

---

## 🔹 **Cell 5: Detect Outliers (Boxplot)**

```python
plt.figure(figsize=(8,5))

num_cols = list(df.select_dtypes(include=np.number).columns)

df.boxplot(column=num_cols)

plt.title("Outlier Detection")
plt.xticks(rotation=30)
plt.show()
```

**Explanation:**
Used boxplot to visually identify outliers in numeric columns.

---

## 🔹 **Cell 6: Remove Outliers (IQR + Print Output)**

```python
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1

    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR

    print(f"\nColumn: {col}")
    print(f"Q1 = {Q1}, Q3 = {Q3}, IQR = {IQR}")
    print(f"Lower Bound = {lower}, Upper Bound = {upper}")

    before = df.shape[0]

    df = df[(df[col] >= lower) & (df[col] <= upper)]

    after = df.shape[0]

    print(f"Rows before: {before}, Rows after: {after}")
    print(f"Outliers removed: {before - after}")
```

**Explanation:**
Applied IQR method to detect and remove outliers while printing bounds and number of removed rows.
