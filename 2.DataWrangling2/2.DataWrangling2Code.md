Create an “Academic performance” dataset of students and perform the following operations using 
Python.

3. Apply data transformations on at least one of the variables. The purpose of this 
transformation should be one of the following reasons: to change the scale for better 
understanding of the variable, to convert a non-linear relation into a linear one, or to

## 🔹 **Cell 4: Handle Missing Values & Inconsistencies**

```python
# Fill numeric with mean
num_cols = df.select_dtypes(include=np.number).columns

for col in num_cols:
    df[col] = df[col].fillna(df[col].mean())

# Fill categorical with mode
cat_cols = df.select_dtypes(include='object').columns

for col in cat_cols:
    df[col] = df[col].fillna(df[col].mode()[0])

# Remove duplicates
df.drop_duplicates(inplace=True)
```

**Explanation:** Clean dataset by handling missing values and removing duplicates.

## 🔹 **Cell 7: Outlier Detection (IQR + Print)**

```python
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1

    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR

    print(f"\nColumn: {col}")
    print(f"Lower Bound = {lower}, Upper Bound = {upper}")
```

**Explanation:** Calculate IQR bounds for detecting outliers.

---

## 🔹 **Cell 8: Remove Outliers**

```python
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1

    lower = Q1 - 1.5 * IQR
    upper = Q3 + 1.5 * IQR

    df = df[(df[col] >= lower) & (df[col] <= upper)]
```

**Explanation:** Remove rows outside IQR range.
