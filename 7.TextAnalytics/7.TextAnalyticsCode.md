# 🔷 **Cell 1: Import Libraries**

```python id="txt1"
import nltk

from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
from nltk.stem import PorterStemmer, WordNetLemmatizer
from nltk import pos_tag

from sklearn.feature_extraction.text import TfidfVectorizer
```

**Explanation:**
Imported required libraries for NLP preprocessing and TF-IDF representation.

---

# 🔷 **Cell 2: Download NLTK Resources**

```python id="txt2"
nltk.download('punkt')
nltk.download('punkt_tab')
nltk.download('averaged_perceptron_tagger')
nltk.download('stopwords')
nltk.download('wordnet')
```

**Explanation:**
Downloaded required NLTK datasets and tokenizer resources.

---

# 🔷 **Cell 3: Sample Document**

```python id="txt3"
text = """
Text analytics is the process of converting unstructured text into meaningful data.
Natural Language Processing helps computers understand human language.
"""

print(text)
```

**Explanation:**
Created sample document for text preprocessing.

---

# 🔷 **Cell 4: Tokenization**

```python id="txt4"
tokens = word_tokenize(text)

print("Tokens:\n")
print(tokens)
```

**Explanation:**
Split document into individual words and symbols called tokens.

---

# 🔷 **Cell 5: POS Tagging**

```python id="txt5"
pos_tags = pos_tag(tokens)

print("POS Tags:\n")
print(pos_tags)
```

**Explanation:**
Assigned grammatical tags such as noun, verb, adjective, etc.

---

# 🔷 **Cell 6: Stop Words Removal**

```python id="txt6"
stop_words = set(stopwords.words('english'))

filtered_tokens = [
    word for word in tokens
    if word.lower() not in stop_words
]

print("After Stopword Removal:\n")
print(filtered_tokens)
```

**Explanation:**
Removed common words like “is”, “the”, and “of”.

---

# 🔷 **Cell 7: Stemming**

```python id="txt7"
stemmer = PorterStemmer()

stemmed_words = [
    stemmer.stem(word)
    for word in filtered_tokens
]

print("Stemmed Words:\n")
print(stemmed_words)
```

**Explanation:**
Reduced words to root forms using stemming.

---

# 🔷 **Cell 8: Lemmatization**

```python id="txt8"
lemmatizer = WordNetLemmatizer()

lemmatized_words = [
    lemmatizer.lemmatize(word)
    for word in filtered_tokens
]

print("Lemmatized Words:\n")
print(lemmatized_words)
```

**Explanation:**
Converted words into meaningful base forms.

---

# 🔷 **Cell 9: TF-IDF Representation**

```python id="txt9"
documents = [
    "Text analytics converts text into data",
    "NLP helps computers understand language",
    "Text preprocessing improves text analysis"
]

vectorizer = TfidfVectorizer()

tfidf_matrix = vectorizer.fit_transform(documents)

print("TF-IDF Matrix:\n")
print(tfidf_matrix.toarray())

print("\nFeature Names:\n")
print(vectorizer.get_feature_names_out())
```

**Explanation:**
Calculated TF-IDF values to represent text numerically.

---

# 🔷 **Cell 10: Final Output**

```python id="txt10"
print("Text Analytics Completed Successfully")
```

**Explanation:**
Displayed completion message.

### 17. Difference between stemming and lemmatization?

| Stemming                  | Lemmatization             |

# 🔹 **TF-IDF**

### 18. What is TF?

**Answer:**
Term Frequency measures how often a word appears in a document.

---

### 19. What is IDF?

**Answer:**
Inverse Document Frequency measures importance of a word across documents.

---

### 20. What is TF-IDF?

**Answer:**
A numerical representation showing importance of words in documents.

---

### 21. Why use TF-IDF?

**Answer:**
To convert text into machine-readable numeric form.

---

### 22. What happens if a word appears in all documents?

**Answer:**
Its IDF value becomes low because it is less important.
