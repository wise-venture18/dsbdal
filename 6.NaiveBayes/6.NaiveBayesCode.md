# 🔷 **Cell 1: Import Libraries**

```python id="ps6c1"
import pandas as pd
import numpy as np

from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import confusion_matrix, accuracy_score
```

**Explanation:**
Imported libraries for data handling, Naïve Bayes model, and evaluation.

---

# 🔷 **Cell 2: Load Dataset**

```python id="ps6c2"
df = pd.read_csv("iris.csv")

df.head()
```

**Explanation:**
Loaded Iris dataset and displayed first 5 rows.

---

# 🔷 **Cell 3: Dataset Information**

```python id="ps6c3"
df.info()
df.describe()
```

**Explanation:**
Checked structure and statistical summary.

---

# 🔷 **Cell 4: Check Column Names**

```python id="ps6c4"
print(df.columns)
```

**Explanation:**
Verified actual dataset column names.

---

# 🔷 **Cell 5: Select Features and Target**

## For Your Dataset Format

```python id="ps6c5"
X = df[['sepal_length', 'sepal_width', 'petal_length', 'petal_width']]

y = df['species']

print(y.unique())
```

**Explanation:**
Selected flower measurements as features and species as target variable.

---

# 🔷 **Cell 6: Train-Test Split**

```python id="ps6c6"
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
```

**Explanation:**
Split dataset into training and testing sets.

---

# 🔷 **Cell 7: Train Naïve Bayes Model**

```python id="ps6c7"
model = GaussianNB()

model.fit(X_train, y_train)
```

**Explanation:**
Trained Gaussian Naïve Bayes classification model.

---

# 🔷 **Cell 8: Predictions**

```python id="ps6c8"
y_pred = model.predict(X_test)

print("Predicted Values:\n", y_pred[:10])
```

**Explanation:**
Predicted flower species for test data.

---

# 🔷 **Cell 9: Accuracy**

```python id="ps6c9"
accuracy = accuracy_score(y_test, y_pred)

print("Accuracy:", accuracy)
```

**Explanation:**
Calculated overall model accuracy.

---

# 🔷 **Cell 10: Confusion Matrix**

```python id="ps6c10"
cm = confusion_matrix(y_test, y_pred)

print("Confusion Matrix:\n", cm)
```

**Explanation:**
Generated confusion matrix to evaluate classification performance.

---

# 🔷 **Cell 11: TP, TN, FP, FN**

## Binary Example Using First Class

```python id="ps6c11"
TP = cm[0][0]

FP = cm[1][0] + cm[2][0]

FN = cm[0][1] + cm[0][2]

TN = cm.sum() - (TP + FP + FN)

print("TP:", TP)
print("TN:", TN)
print("FP:", FP)
print("FN:", FN)
```

**Explanation:**
Calculated TP, TN, FP, and FN considering first species as positive class.

---

# 🔷 **Cell 12: Precision, Recall, Error Rate**

```python id="ps6c12"
precision = TP / (TP + FP)

recall = TP / (TP + FN)

error_rate = 1 - accuracy

print("Precision:", precision)
print("Recall:", recall)
print("Error Rate:", error_rate)
```

**Explanation:**
Calculated evaluation metrics.

# 🔹 **Evaluation Metrics**

### 22. What is accuracy?

Accuracy = \frac{TP + TN}{TP + TN + FP + FN}

**Answer:**
Percentage of correctly predicted observations.

---

### 23. What is precision?

Precision = \frac{TP}{TP + FP}

**Answer:**
Correctness of positive predictions.

---

### 24. What is recall?

Recall = \frac{TP}{TP + FN}

**Answer:**
Ability to identify actual positive cases.

---

### 25. What is error rate?

Error\ Rate = 1 - Accuracy

**Answer:**
Percentage of incorrect predictions.
