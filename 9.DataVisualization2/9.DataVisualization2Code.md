
# 🔷 **Cell 2: Load Titanic Dataset**

```python id="ps9c2"
df = sns.load_dataset('titanic')

df.head()
```

**Explanation:**
Loaded inbuilt Titanic dataset from Seaborn.

---

# 🔷 **Cell 3: Dataset Information**

```python id="ps9c3"
df.info()
```

**Explanation:**
Checked dataset structure and columns.

---

# 🔷 **Cell 4: Boxplot of Age by Gender and Survival**

```python id="ps9c4"
plt.figure(figsize=(8,6))

sns.boxplot(
    x='sex',
    y='age',
    hue='survived',
    data=df
)

plt.title("Age Distribution by Gender and Survival")

plt.show()
```

**Explanation:**
Displayed boxplot of age distribution for males and females based on survival status.

---

# 🔷 **Cell 5: Final Output**
