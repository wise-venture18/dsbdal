```python id="ps10c2"

df.head()
```

# 🔷 **Cell 3: Dataset Information**

```python id="ps10c3"
df.info()
```

**Explanation:**
Checked dataset structure and data types.

---

# 🔷 **Cell 4: List Features and Types**

```python id="ps10c4"
print("Features and Data Types:\n")

print(df.dtypes)
```

**Explanation:**
Displayed all features and their data types.

---

# 🔷 **Cell 5: Numeric and Nominal Features**

```python id="ps10c5"
numeric_features = df.select_dtypes(include=['float64', 'int64']).columns

nominal_features = df.select_dtypes(include=['object']).columns

print("Numeric Features:\n", numeric_features)

print("\nNominal Features:\n", nominal_features)
```

**Explanation:**
Separated numeric and nominal features.

---

# 🔷 **Cell 6: Histograms for Each Feature**

```python id="ps10c6"
df.hist(figsize=(10,8))

plt.suptitle("Histogram of Iris Features")

plt.show()
```

**Explanation:**
Displayed histogram for each numeric feature to observe distributions.

---

# 🔷 **Cell 7: Boxplots for Each Feature**

```python id="ps10c7"
plt.figure(figsize=(10,6))

sns.boxplot(data=df.select_dtypes(include=['number']))

plt.title("Boxplot of Iris Features")

plt.show()
```

**Explanation:**
Displayed boxplots for numeric features to analyze spread and outliers.

---

# 🔷 **Cell 8: Individual Boxplots**

```python id="ps10c8"
for col in numeric_features:
    
    plt.figure(figsize=(5,4))
    
    sns.boxplot(y=df[col])
    
    plt.title(f"Boxplot of {col}")
    
    plt.show()
```

**Explanation:**
Displayed separate boxplot for each feature.

---
