## 🔹 **Cell 1: Import Libraries**

```python id="ps5final1"
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix
```

**Explanation:**
Imported libraries for data handling, visualization, model training, and evaluation.

---

## 🔹 **Cell 2: Load Dataset**

```python id="ps5final2"
df = pd.read_csv("Social_Network_Ads.csv")

df.head()
```

**Explanation:**
Loaded dataset and displayed first 5 rows.

---

## 🔹 **Cell 3: Dataset Information**

```python id="ps5final3"
df.info()
df.describe()
```

**Explanation:**
Checked data types and statistical summary.

---

## 🔹 **Cell 4: Check Column Names**

```python id="ps5final4"
print(df.columns)
```

**Explanation:**
Verified actual dataset column names.

---

## 🔹 **Cell 5: Select Features and Target**

```python id="ps5final5"
X = df[['Age', 'EstimatedSalary']]
y = df['Purchased']

print(y.unique())
```

**Explanation:**
Selected input features and target variable. Printed unique target values to verify binary classes.

---

## 🔹 **Cell 6: Train-Test Split**

```python id="ps5final6"
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
```

**Explanation:**
Split dataset into training and testing sets.

---

## 🔹 **Cell 7: Feature Scaling**

```python id="ps5final7"
scaler = StandardScaler()

X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)
```

**Explanation:**
Scaled features for improved model performance.

---

## 🔹 **Cell 8: Train Logistic Regression Model**

```python id="ps5final8"
model = LogisticRegression()

model.fit(X_train, y_train)
```

**Explanation:**
Trained Logistic Regression classification model.

---

## 🔹 **Cell 9: Predictions**

```python id="ps5final9"
y_pred = model.predict(X_test)

print("Predicted Values:\n", y_pred[:10])
```

**Explanation:**
Predicted class labels for test data.

---

## 🔹 **Cell 10: Confusion Matrix**

```python id="ps5final10"
cm = confusion_matrix(y_test, y_pred)

print("Confusion Matrix:\n", cm)
```

**Explanation:**
Generated confusion matrix to evaluate predictions.

---

## 🔹 **Cell 11: TP, TN, FP, FN**

```python id="ps5final11"
TN = cm[0][0]
FP = cm[0][1]
FN = cm[1][0]
TP = cm[1][1]

print("True Positive (TP):", TP)
print("True Negative (TN):", TN)
print("False Positive (FP):", FP)
print("False Negative (FN):", FN)
```

**Explanation:**
Extracted confusion matrix values.

---

## 🔹 **Cell 12: Accuracy, Error Rate, Precision, Recall**

```python id="ps5final12"
accuracy = (TP + TN) / (TP + TN + FP + FN)

error_rate = 1 - accuracy

precision = TP / (TP + FP)

recall = TP / (TP + FN)

print("Accuracy:", accuracy)
print("Error Rate:", error_rate)
print("Precision:", precision)
print("Recall:", recall)
```

**Explanation:**
Calculated evaluation metrics for the classification model.

---
